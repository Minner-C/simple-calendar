# 宝塔面板部署 SimpleCalendar 后台教程（PHP + MySQL 版）

本文以宝塔 Linux 面板（8.x / 9.x）为例，把 `backend/` 目录部署到线上，
最终得到：
- 接口：`https://你的域名/api/holidays`
- 管理后台：`https://你的域名/admin.html`（纯 HTML 页面，数据通过 `admin_api.php` 读写）

宝塔原生支持 PHP + MySQL，不需要装 Node、不需要常驻进程。

---

## 1. 准备环境

登录宝塔面板 → **软件商店**，确认已安装：

- **Nginx**（或 Apache，二选一）
- **MySQL 5.7+**（或 MariaDB 10.x）
- **PHP 7.4 或更高版本**

## 2. 创建数据库

宝塔 → **数据库** → **添加数据库**：

| 配置项 | 填写 |
|--------|------|
| 数据库名 | `simple_calendar` |
| 用户名 | `simple_calendar`（自动同名） |
| 密码 | 设一个强密码，记下来 |
| 访问权限 | 本地服务器（127.0.0.1）即可 |

创建后点该数据库的 **管理** 进入 phpMyAdmin → 选中数据库 → **导入** → 选择 `backend/install.sql` → 执行。
完成后能看到 `admins`、`holidays`、`almanac`、`ads`、`ad_clicks` 五张表，`holidays` 里已有 2025–2026 的数据。

## 3. 添加站点

**网站** → **添加站点**：

| 配置项 | 填写 |
|--------|------|
| 域名 | 你的域名，如 `api.example.com`（提前把 A 记录解析到服务器 IP） |
| 根目录 | 保持默认，如 `/www/wwwroot/api.example.com` |
| PHP 版本 | 选已安装的任意版本（**不要选"纯静态"**） |

## 4. 上传代码并修改配置

把 `backend/` 目录里的文件上传到站点根目录（`index.php`、`admin.html`、`admin_api.php`、`config.php`、`db.php`、`.htaccess`）。

然后在宝塔 **文件** 面板里直接编辑 `config.php`，填入第 2 步的数据库账号密码：

```php
'db_dsn'  => 'mysql:host=127.0.0.1;port=3306;dbname=simple_calendar;charset=utf8mb4',
'db_user' => 'simple_calendar',
'db_pass' => '你第 2 步设的数据库密码',
```

> 管理后台的登录账号在数据库里（初始 **admin / admin123**），不在配置文件中，
> 首次登录后请立即在"账号管理"里修改密码。

## 5. 配置伪静态（Nginx 必做）

站点设置 → **伪静态**，填入：

```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}
```

> Apache 建站则跳过此步，代码里已带 `.htaccess`。

## 6. 配置 HTTPS

站点设置 → **SSL** → **Let's Encrypt** → 勾选域名 → **申请**，成功后开启 **强制 HTTPS**。

## 7. 验证

```text
https://api.example.com/api/holidays                 → 节假日 JSON
https://api.example.com/api/holidays/check/2026-10-01 → 单日查询
https://api.example.com/admin.html                   → 管理后台登录页
```

登录管理后台随便改一条数据，再访问对应 API，应该立即看到变化。

## 8. 防火墙检查

只需对外开放 **80 / 443**。MySQL 的 3306 不要对外开放（站点和数据库同机，走 127.0.0.1）。

## 9. 配置客户端

- 软件 **设置** → 后台 API 地址，填 `https://api.example.com/api`
- 或直接改 `%APPDATA%\SimpleCalendar\clock_settings.json` 里的 `ApiUrl`

## 10. 日常维护

- **更新节假日**：登录 `admin.html` → 节假日标签页，按年浏览、增删改，保存即生效。每年国务院公布放假安排后更新一次。
- **管理广告**：广告位标签页，留空则客户端不显示广告；点击量看"点击统计"标签页。
- **管理账号**：账号管理标签页可改自己密码、增删管理员（初始 admin / admin123）。
- **改数据库密码**：编辑站点根目录的 `config.php`。

## 常见问题

**Q: 访问 `/api/holidays` 返回 404？**
伪静态没配（第 5 步）。访问 `/index.php` 能出 JSON 但 `/api/...` 404，就是这个问题。

**Q: 接口报数据库连接错误？**
`config.php` 里的库名/用户名/密码与宝塔创建的不一致，或 MySQL 没启动（宝塔 → 数据库 里看状态）。

**Q: Let's Encrypt 申请失败？**
域名没解析到本机，或 80 端口没放行。先保证 `http://域名` 能访问再申请。

**Q: 后台登录提示"账号或密码错误"？**
管理员账号在数据库 `admins` 表里。忘记密码时，到 phpMyAdmin 的 `admins` 表把
`password_hash` 重置为 `$2y$10$hllIFGFoAPmXNhi.BUGqy.crEWkFlhSpP5IZ0IMNKIdnuPq9rB8v2`（即 admin123），
登录后立即修改。
